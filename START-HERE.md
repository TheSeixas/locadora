# BDK Locadora — versão final

## Executar no Windows

1. Abra esta pasta no Explorador.
2. Abra um terminal nesta pasta.
3. Execute `run.bat`.
4. Abra `http://127.0.0.1:3000/`.

## Contas de demonstração

- `admin / admin123`
- `operador / op123`
- `crianca / kids123`
- `inativo / inactive123`
